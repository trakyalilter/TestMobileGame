# UI RULES — GAME FEEL

UI must feel like a GAME, not an OEM app.

- One primary focus per screen
- Secondary info is suppressible

#HIERARCHY
- One primary focus per screen
- Secondary info is suppressible

#FEEDBACK
- Every action gives feedback
- No silent progress

#IDLE SAFETY
- UI complexity decreases with automation
- Visual entropy must not increase over time

#FORBIDDEN
- App-like layouts
- Spreadsheet visuals
- Clicks without feedback
