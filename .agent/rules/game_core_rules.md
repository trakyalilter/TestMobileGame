# GAME CORE RULES — IDLE SCI-FI GAME MCP

This document defines the NON-NEGOTIABLE core rules
for the idle sci-fi game.

These rules override convenience, creativity, and short-term fun.
They exist to protect long-term balance, clarity, and player trust.

If a design decision violates any rule here, it is INVALID.

CORE IDENTITY
- Idle-first, active-accelerated
- Systems-driven, not content-driven
- No mandatory micromanagement

CORE LOOP
WAIT → COLLECT → CONVERT → INVEST → UNLOCK → WAIT

- Every resource must participate
- Every loop iteration must alter player state


TIME VALIDATION
The loop must function at:
- 10 seconds
- 10 minutes
- 10 hours
