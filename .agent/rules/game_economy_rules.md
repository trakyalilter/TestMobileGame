# ECONOMY RULES

Economy must be stable, scalable, and abuse-resistant.

#Source → Sink Balance
- Every resource has at least one sink
- No permanent source without scaling cost


#Scaling
- Early: linear
- Mid: controlled exponential
- Late: soft caps / logarithmic

#Forbidden
- Infinite exponentials
- Hidden multipliers
- Dead resources
