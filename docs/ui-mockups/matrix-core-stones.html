Matrix Cores — As Stones

Right now the in-engine core reads as a glowing energy core (white-hot nucleus + plasma halo). These are solid, top-lit, faceted GEMSTONES — mineral, not plasma. Colour-agnostic: the facet light/shadow are white/black overlays on the base gem colour, so all 4 core colours (and any future ones) work from one routine.
01 · Cut Gem — the 4 core colours
Tier progression (Crimson) — cut quality rises with tier
Cracked = chipped + a fracture line, duller. Stable = clean cut. Pristine = extra facets + brighter rim + sparkle. The stone literally looks more refined as it upgrades — readable progression with zero text.
Other stone vibes (Amethyst) — if "cut jewel" feels too clean
Rough Crystal = raw mined shard (asymmetric, matte). Cabochon = polished tumbled stone (smooth dome). My pick is 01 Cut Gem — it reads "valuable socketable gem" instantly and the tier-as-cut-quality progression is a free win.
