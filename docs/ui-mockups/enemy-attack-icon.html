Attack Icon — On-Theme Options

Crossed swords are melee/fantasy — wrong for ship weapons. ATK = the enemy's firepower (the KIN/NRG/EXP type is already shown as text + resist chips), so the icon should be a type-neutral weapon/targeting mark. Heart (HP) and shield (DEF) stay — both read fine in sci-fi. Shown at the real 15px card size, amber-tinted.

My pick: 1 · Target Reticle. It's the universal sci-fi "combat/lock-on" mark, type-neutral, bold and unmistakable at 15px, and visually distinct from the heart/shield silhouettes (open vs solid) so the row scans fast. 4 · Impact Burst is the close second if you'd rather the icon say "damage dealt" than "targeting." 3 · Crossed Barrels keeps the old crossed-weapons gestalt but re-themed — pick it only if you liked the "crossed = attack" reading. 2 · Bolt is punchy but leans toward reading as energy-type specifically.
