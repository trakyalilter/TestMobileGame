Offline Welcome-Back · Redesign Directions

The return screen is the idle genre's single biggest retention beat — the "fat report" dopamine hit. Today it's flat left-aligned text on a void. Same sample data in every mock: 15h 11m away · Excavate Soil (911m, 13,675 actions, +109.4K XP, +218,800 Dirt), plus a Refinery + Infrastructure block to show how each design scales to multiple activities and handles upkeep drains (red) and Liras.

My pick: A (Mission Debrief). It's the most scannable, scales cleanly to N activity blocks, surfaces the hero numbers first, and reuses the Cargo-Manifest loot chips we already shipped — so it feels native, not bolted on. B is the coolest theme but monospace+glow costs readability at a glance; C celebrates loot hardest but buries per-skill XP, which matters for a skilling idle. Easy to graft C's loot tokens into A's loot row if you want more treasure-punch.
