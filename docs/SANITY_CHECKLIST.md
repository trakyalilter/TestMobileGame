# Horizon Idle — Senior-Designer Sanity Check List

**How to use this.** Run this as a pre-build and pre-release gate: check each box against the *live build or the actual code*, not against your memory of how the system "should" work — the codebase has a documented history of UI/sim desync and missed migrations. A `Verify` step you didn't actually run is an **unchecked box**, not a pass. Every 🔴 in the Release Blockers list must pass before you ship a Steam build.
